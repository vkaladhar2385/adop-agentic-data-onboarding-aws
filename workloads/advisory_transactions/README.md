# Workload: `advisory_transactions`

Daily brokerage / advisory transaction pipeline for a wealth-management firm.
Generated by the ADOP Data Onboarding Agent as a **SOX**-compliant medallion
pipeline (Bronze -> Silver -> Gold star schema), orchestrated by **Step Functions
+ EventBridge** (no MWAA).

## What this workload does
1. **Bronze** — ingest the daily CSV immutably (raw, all-string, partitioned by `ingestion_date`).
2. **Silver** — dedup on `transaction_id`, type-cast, trim/uppercase, **mask PII**
   (SSN/email + pseudonymise client id), and **quarantine** rows that fail
   critical validity/financial checks (never dropped silently).
3. **Silver quality gate** — score must be >= 0.80 and no critical rule may fail.
4. **Gold** — build a **star schema**: `fact_transactions` + `dim_account` /
   `dim_advisor` / `dim_security` / `dim_date`, plus a `gold_advisor_daily_summary`
   rollup. PII (SSN/email/name) is **suppressed** entirely in Gold.
5. **Gold quality gate** — score must be >= 0.95 and no critical rule may fail.
6. **Catalog + LF-Tags** — register Iceberg tables, apply Lake Formation tags for
   column-level (TBAC) access control.
7. **Verify** — 5+ automated post-deploy checks must pass.

## SOX controls baked in
| Control | Where |
|---|---|
| Financial integrity (gross/net formulas) | `config/quality_rules.yaml` (critical) |
| Immutable Bronze | `sql/bronze/…` + `bronze-immutable` invariant |
| 7-year retention | `config/source.yaml` |
| PII masking + suppression | `config/transformations.yaml`, `shared/utils/pii.py` |
| Human review of bad rows | quarantine side-table |
| Zone-scoped KMS | `iac/terraform/main.tf` |
| Audit logging | CloudTrail via post-deploy verifier |

## Run the demo locally (no AWS)
```bash
pip install -r requirements.txt
python demo/data_generators/generate_advisory_transactions.py
python workloads/advisory_transactions/scripts/run_local_pipeline.py
pytest workloads/advisory_transactions/tests/ -v
```

## Folder map
```
config/          declarative source of truth (source/semantic/transformations/quality/schedule)
scripts/         extract, transform (Bronze->Silver->Gold), quality, load  (+ local_runner core)
sql/             Athena/Iceberg DDL per zone
orchestration/   Step Functions ASL + EventBridge schedule
tests/           unit + integration (run with pytest, no AWS)
memory/          persistent workload learnings
```

Production Glue/PySpark and local pandas share the SAME config files, so demo
behaviour cannot drift from what runs on AWS.

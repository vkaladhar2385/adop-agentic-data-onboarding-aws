Business & value

QuestionAnswer
ROI?Illustrative ~14 engineer-days → ~0.5 day per source once factory pattern is in place.
Production-ready?Pattern proven; client adapts IAM, VPC, modules, compliance.
Lock-in?Specs + templates in git; Terraform + Glue/Iceberg — portable, not black-box SaaS.
Cost?Serverless per run; ~$2–5 demo; destroy sandbox — $0 idle.
vs Databricks / Snowflake?Complementary — AWS-native onboarding factory, not a warehouse replacement.
Plug into our lake?Yes — same S3/Glue/LF model; map buckets, roles, modules (ADAPTATION_GAP.md).

Factory · HITL · drift

QuestionAnswer
What is HITL?Human-in-the-loop — you answer discovery rules + say I approve deploy; agent doesn’t guess PK/PII.
Agent autonomous?No — discovery gate, deploy gate, write guard on generated scripts.
Drift-checked scripts?spec_hash in generated .py; CI re-renders from YAML — hand-edits fail.
Replace data engineers?No — they own business rules & approval; factory removes boilerplate.
Quality gates 0.80 / 0.95?Rule scores from quality_rules.yaml; SFN stops if gate fails — not checksums.
Why Iceberg?ACID on S3, time travel, Glue catalog; Silver/Gold need Spark (glueetl).

MCP · hybrid · Terraform (Slides 6–7)

QuestionAnswer
Is MCP the pipeline?No. MCP = agent deploy toolbelt (Operations). Pipeline = Glue + Step Functions in AWS.
Does data run on the laptop?No. Hybrid/local only changes how Cursor calls tools. Bronze→Gold runs in AWS.
MCP vs Terraform?MCP: catalog, LF, metadata. Terraform: Glue jobs, Lambda, Step Functions.
Does MCP create Glue jobs?No. MCP creates database/tables; Terraform creates job definitions.
Why two tools?One owner per ARN — declared in compute.yaml; CI catches drift.
Phase 0 health check?Preflight before deploy — confirms glue-athena, lakeformation, iam MCP tools are wired.
